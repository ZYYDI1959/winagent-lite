## 七大发现

1. **眼睛模型梯度**（同一时钟任务）：3b 完全看不见 / 7b 看得见但坐标系统性偏 6px、容差偏移 100% 自愈 / 27b 看得见但偏到相邻元素且慢 10 倍。**7b+容差是性价比甜点。**
2. **WinUI 应用不接受 UNICODE 注入的运算符**：计算器 0/5→5/5 的唯一改动是 `*`/`=` 改走虚拟键。
3. **中文 IME 劫持虚拟键路径**：VK 打字出现大小写漂移（LINE-2-WinAgent→line-2-WinAGENT）。最终策略：字母/数字/空格/中文走 UNICODE（绕 IME），仅 ASCII 标点运算符走虚拟键（原子 SendInput）。
4. **对话框不等价**：Win+R 运行框 5/5 全过；另存为框对合成键盘免疫（IME+自动补全陷阱）。交互原语选择决定成败。
5. **提权窗口对非提权 agent 免疫**：管理员任务管理器（置顶）+ 提权僵尸记事本（单实例吞标签页）曾阻塞全部 notepad 任务；taskkill/SetForegroundWindow/真实点击均无效。评测 setup 必须清场。
6. **Win11 记事本会话恢复复活未保存标签**：TabState 残留导致每次启动恢复旧标签、新输入打进旧文档、Ctrl+S 变另存为。setup 加 `clear_notepad_session` 动词根治。
7. **视觉点击定位的是"位置"不是"文末"**：点击编辑区会把光标放在点击处（文字中间），打字前必须 Ctrl+End。另：焦点等待就够时免视觉点击可省 88% 耗时（29.7s→2.7s）。
