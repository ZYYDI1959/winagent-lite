## 基线五大发现

1. **眼睛模型梯度清晰**（同一时钟任务）：3b 完全看不见 / 7b 看得见但坐标系统性偏 6px、被容差偏移机制 100% 自愈 / 27b 看得见但偏到相邻元素且慢 10 倍。**7b+容差 是性价比甜点。**
2. **WinUI 应用不接受 UNICODE 注入的运算符**：计算器 0/5→5/5 的唯一改动是 ASCII 字符改走虚拟键（VkKeyScanW）路径。
3. **对话框不等价**：Win+R 运行框 5/5 全过；另存为框对合成键盘免疫（IME+自动补全陷阱）。交互原语选择决定成败。
4. **验证分级必要**：A 级（文件/进程）判定 24 次零误判；B 级（VLM 看图）仅用于计算器结果，单次 ~25s。
5. **提权窗口对非提权 agent 免疫**：管理员权限的任务管理器（置顶）+ 提权僵尸记事本（单实例合并标签页）导致 3 任务阻塞；taskkill/SetForegroundWindow/真实点击均无效。评测必须控制环境（setup 清场），遇到提权元素需人工配合。
